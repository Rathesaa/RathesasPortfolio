Project 04 · Job aid · Visual communication

Making Complex Information Easier to Use

A documentation and visual-communication concept that helps people find guidance while completing a task.

At a glance

Figma · Adobe tools · Microsoft 365 · SharePoint · Plain-language writing

The learning problem

When instructions are lengthy or difficult to scan, users may struggle to find the right step at the moment they need it. Not every learning need requires a course.

Target audience

Employees who need to complete a repeatable process or use an unfamiliar system. The final guide should be tailored to a specific task and validated with its users.

Learning objectives

By the end of this learning experience, learners should be able to:

  • Locate the correct instruction for each stage of a task.
  • Complete the process using a concise reference guide.
  • Recognize when an issue requires additional help or escalation.

Why this learning method?

Performance support places guidance close to the task. Plain language, visual hierarchy, annotated screenshots, and step-by-step instructions reduce the need to remember every detail.

Design and development

The sample guide would include a clear task title, prerequisites, numbered steps, annotated visuals, decision points, common errors, and a route for getting help. It would be designed for quick scanning rather than long-form reading.

Assessment and evaluation

Ask representative users to complete a task using only the guide. Observe where they pause, make errors, or ask for clarification, then revise the content and layout.

Design reflection

A job aid is most useful when it supports a real task. In a finished portfolio case study, include the actual guide, explain the design decisions, and show what changed after user feedback.
