Project 03 · UX + self-directed learning

LearnFlow: A More Supportive LMS Experience

A learning-management-system concept that brings course discovery, learning materials, and progress into one organized experience.

At a glance

Figma · User flows · Wireframes · Interactive prototyping · Usability testing

The learning problem

Learners can lose time navigating a learning platform, locating materials, and figuring out what to do next. A clearer experience can reduce friction and support independent learning.

Target audience

Employees completing assigned workplace learning as well as learners exploring optional development opportunities.

Learning objectives

By the end of this learning experience, learners should be able to:

  • Find assigned and recommended learning in one place.
  • Understand course progress and next steps.
  • Choose learning resources that relate to their goals.

Why this learning method?

Self-directed learning gives learners visibility and choice. Chunked content and clear progress cues help make a learning pathway easier to navigate. Recommendations should be based on relevant goals and activity, not fixed assumptions about learning styles.

Design and development

The interface concept includes a dashboard, course discovery, course details, learning materials, progress indicators, recommended courses, and quiz feedback. A future feature could suggest resources based on learner goals, completed topics, and expressed interests.

Assessment and evaluation

Usability testing could ask representative learners to find a course, locate a resource, and identify their next step. Measures could include task completion, errors, time on task, and learner feedback.

Design reflection

This project connects UX and learning design. The interface is not the learning strategy by itself; it should make a well-designed learning experience easier to access and complete.
